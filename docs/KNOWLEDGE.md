# Your Knowledge folder

**Everything gigabite knows lives in one place: the `Knowledge` folder in your home
folder.** Open it in Finder any time. What's in it is what Claude can recall, so the
more you put in, the better Claude knows your work.

## How it's organised

- **Every folder in `Knowledge` is a project.** One folder per client, product or
  piece of work.
- **Folders inside a project are layers**, such as `meetings`, `decisions` or
  `delivery`. They keep a project tidy. Create whichever ones suit you.
- **Every project has a `_project.md` file.** It holds the project's keywords: the
  words that tell Claude a message is about that project. Add a background section and
  the key people too if you like.

## Start a project

Ask Claude to create it. The project's name becomes its first keyword automatically.
Add any other words you naturally use for the work, like the client or the product, so
Claude recognises it however you refer to it.

Create projects through Claude rather than by making a new folder in Finder. A folder
without a `_project.md` isn't recognised as a project when Claude recalls.

## Add to it

- **Drop files into the project's folder** (or one of its layers) in Finder: notes,
  specs, meeting transcripts, decks, screenshots. That's all there is to it.
- **Or hand it to Claude.** Paste a transcript or attach a file and ask Claude to file
  it. It lands in the same place as if you'd dragged it there yourself.
- **New files are picked up the next time you start Claude Code.**
- **Text is read in full.** PDFs, images and other files are kept and found by name and
  date, but their contents aren't read.

## Find things

Type `/search` in Claude Code, followed by a few words. It searches every project at once.

## Keep it tidy

- **Move a file to another project** and it belongs to that project from then on.
- **A loose file at the top of `Knowledge`** means gigabite couldn't tell where it
  belonged, so it didn't guess. Drag it into the right project.
- **Rename, reorganise or delete** anything you like. It's your folder.
- **Leave the `.gigabite` folder alone.** It holds the search index, not your content.

## Safe by design

- Nothing in `Knowledge` leaves your Mac.
- Claude only recalls from the project your message is about, so one client's material
  doesn't turn up in another client's work.
- **Back it up.** Everything else can be reinstalled. Your Knowledge folder can't be
  rebuilt.
