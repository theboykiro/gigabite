# SOP: PM Decision

## Purpose

Turn an open product question into a decision the user can act on. The deliverable is
a **recommendation**, backed by the reasoning — not a neutral menu that hands the
judgement back to the user. A decision doc that ends in "it depends" hasn't done its
job.

## When to use

- A product or delivery call with real trade-offs: scope cuts, sequencing, build vs.
  buy, whether to ship now or hold.
- Skip it for reversible, low-cost calls — for those, act and report.

## The sequence

### 1. Frame the decision
- State the decision in one line: what is actually being decided, by when, and what
  becomes possible or blocked once it's made.
- Name the constraints that bound it: deadline, budget, dependencies, non-negotiables.
- Run `gigabite search "<topic / project>"` first — surface prior decisions,
  stakeholder positions, and constraints already on record. Don't reopen a settled
  question or contradict a commitment without flagging it.

### 2. Lay out the options
- Two to four real options. No strawmen padded in to make one look good.
- Include the do-nothing / defer option when it's genuinely live.
- One line each: what it is, what it costs, what it buys.

### 3. Trade-offs
- Compare on the axes that matter for *this* decision (e.g. speed, risk, cost,
  reversibility, stakeholder cost) — not a generic grid.
- Be explicit about what each option sacrifices. Every real option gives something up.

### 4. Recommendation
- **Lead with the call.** State the recommended option plainly and why it wins on the
  axes that matter most here.
- Give the trigger that would change the call — the one fact that, if different, flips
  it. That's how the user pressure-tests it fast.
- Name the first concrete next step.

## Definition of done

- Decision framed in one line with its constraints and deadline.
- Real options with honest trade-offs; do-nothing considered where live.
- A clear recommendation up front — not a survey — with the flip condition stated.
- Prior context checked so nothing contradicts a standing decision unflagged.
- Next step named.
